# MATLAB public-project execution path

The authoritative native acquisition is executed through the pinned MathWorks **Run MATLAB Command** action, not by launching `matlab.exe` directly from a shell.

Controlled native step:

- action: `matlab-actions/run-command`
- release: `v3.2.1`
- immutable commit: `75644028e1e2aa374bbfdc968a65718a178cc264`
- used action inputs: `command`, `generate-summary`
- command: `addpath('scripts'); nref_native_bootstrap`
- GitHub step timeout: 180 minutes

The exact pinned action manifest exposes only `command`, `startup-options`, and `generate-summary` inputs. The controlled native step therefore uses no undocumented action input.

The intended licensing basis is a **public GitHub project** on a GitHub-hosted runner with Setup MATLAB followed by Run MATLAB Command. Repository visibility is part of the execution basis; changing to private requires a separate licensing review.

The MATLAB diary generated by `nref_native_bootstrap` is retained as public native evidence. No synthetic shell-redirected MATLAB stdout/stderr files are created by the harness. GitHub Actions logs remain workflow transport evidence and may be preserved during downstream ingestion.

A failed MATLAB action is not automatically source nonconvergence. `SOURCE_NONCONVERGED` requires explicit native convergence evidence from an actually executed source point.
